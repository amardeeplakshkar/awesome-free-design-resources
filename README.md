# awesome-free-design-resources
> Free photos, icons, fonts & illustrations for makers. Curated, simple, and free to use — one line per entry.
- [Unsplash](https://unsplash.com/) — High-quality free photos
- [Pexels](https://www.pexels.com/) — Free photos and videos
- [unDraw](https://undraw.co/) — Illustrations you can recolour to your brand
- [Lucide](https://lucide.dev/) — Simple, consistent open-source icons
- [Openverse](https://openverse.org/) — Search free images, audio and more
- [Google Fonts](https://fonts.google.com/) — Free fonts for web and print
- [Fontshare](https://www.fontshare.com/) — Quality free fonts for commercial use
